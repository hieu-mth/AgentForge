# LTX Cloud pilot (V5.3)

Standalone, explicitly paid CLI for LTX V2 Text-to-Video or Image-to-Video, not yet bound to Studio timeline or Model Hub. It preserves native audio if requested. No default model, no background processing, no automatic POST retry, no credential persistence. The API key is only read from LTX_API_KEY in the local terminal. The SQLite ledger lives under the user's .agentforge directory; all reserved seconds, even unknown/failed requests, count against the explicit cumulative pilot seconds cap. The cap limits generated seconds, not provider charges, taxes, or external account use.

Use a unique stable lowercase UUID hex ID generated by Python, then run:

```powershell
$id = python -c "import uuid; print(uuid.uuid4().hex)"
python -m agentforge.features.film_studio.studio_ltx_cloud submit $id --model ltx-2-3-fast --prompt "A cat walks slowly in a garden" --seconds 6 --max-seconds 6 --confirm-paid
python -m agentforge.features.film_studio.studio_ltx_cloud poll $id
```

Poll again after at least 5 seconds if still pending. Do not submit a new ID after an ambiguous failure: reconcile the provider billing and job first. The pilot supports landscape 720p, 24 fps, 6/8/10 seconds. Image input requires explicit --image and the media extra. Default output is ~/.agentforge/ltx-output. Only the documented GCS result host is currently accepted; other delivery hosts fail closed. MP4 verification covers video dimensions, rate, decoded frame count and SHA; audio and creative quality are not certified.

Official references: https://docs.ltx.io/async-jobs/ and https://docs.ltx.io/models/ltx-2-3/ and https://docs.ltx.io/pricing.
